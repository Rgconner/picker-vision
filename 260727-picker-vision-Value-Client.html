B07 (Label Sheet Generator, XL, 140 hrs): Dual print mode, 3 barcode types, PDF generation. Highest single-item estimate in the project — validate Avery label alignment with physical test prints before customer demo.

P06 + P07 (Pi pipeline, 152 hrs): Threading model on Pi hardware is environment-dependent — test on target hardware before live demo.
